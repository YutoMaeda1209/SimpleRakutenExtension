# SimpleRakutenExtension 概要

## 目的

PC版（Web）楽天市場の商品ページは、大量の商品画像が上部を占領しており、肝心の商品説明やカートボタンにたどり着くまでに大量のスクロールが必要になる。

本拡張機能はこの問題を解決し、Amazonのように商品説明がページ上部に来るレイアウトに変換することを目的とする。

## 対象

- **プラットフォーム**: PC版 Chromeブラウザ
- **対象サイト**: 楽天市場 商品ページ（`item.rakuten.co.jp`）
- **配布**: Chrome Web Store にて一般公開

## 主な機能

### 商品画像のスライドショー化

商品ページから画像を収集し、スライドショー形式で表示する。左右ボタン・サムネイル・キーボード（← →）で操作できる。画像をクリックするとライトボックスで拡大表示される。

### スクロール量の削減

画像集約により、カートボタン・商品説明セクションをページ上部付近に配置する。ユーザーが商品の詳細情報にすばやくアクセスできるようにする。

### ショップトップへのリンク

ページ上部にショップのトップページへのリンクを表示する。

## 解決する課題

| 現状 | 改善後 |
|---|---|
| 商品画像が縦に並び、ページ上部を大きく占有する | 画像はスライドショーに集約され、コンパクトに表示される |
| 商品説明まで大量のスクロールが必要 | カートボタン・商品説明がすぐ目に入る位置に表示される |
